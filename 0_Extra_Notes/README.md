# Best Way to Study Each Topic

Use this structure for every Azure service:

## For every concept, learn these 7 things

1. What is it?
2. Why do we use it?
3. Where is it used in real projects?
4. How does it work internally?
5. How to create it from Azure Portal?
6. How to create it using Azure CLI?
7. How to create it using Terraform?
