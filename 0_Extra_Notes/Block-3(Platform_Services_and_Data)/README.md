# Block 3: Platform Services and Data

## Covers:

- App Service
- Azure Functions
- Storage Accounts
- Blob Storage
- Azure Files
- VM Disks
- Azure SQL
- Cosmos DB
- Backup
- DR
- Migration
- Service Bus

This block is about using Azure managed services instead of managing everything manually.

## Focus on:

- When to use VM vs App Service vs Azure Functions
- When to use Blob Storage vs Azure Files vs Disk
- Hot, Cool, Cold, and Archive tiers
- LRS, ZRS, GRS, RA-GRS
- SAS token
- Access keys
- Private endpoint
- Azure SQL vs Cosmos DB
- Queue vs Topic vs Subscription in Service Bus
- Dead Letter Queue

## Your target:

You should be able to say:

> "If I need to host a web app, I can use App Service. If I need event-driven code, I can use Azure Functions. If I need object storage, I use Blob Storage. If I need relational database, I use Azure SQL. If I need globally distributed NoSQL, I use Cosmos DB. If I need asynchronous messaging, I use Service Bus."

That clarity matters.
